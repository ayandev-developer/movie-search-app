# Movie Search App

A movie search application built using HTML, CSS, and JavaScript. It uses the OMDb API to retrieve movie information.

## Features

* Search for movies by title
* Display movie cards with poster images
* Show a fallback when a poster is unavailable
* Handle loading and error states
* Search using the Enter key
* Responsive movie grid layout

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Fetch API
* Async/Await
* DOM Manipulation
* OMDb API
* CSS Grid

## What I Learned

* Fetching and displaying API data
* Creating dynamic movie cards
* Handling errors and missing poster images
* Building responsive layouts
* Improving user interaction and accessibility
